# ML-Employee-Attrition-and-Risk-Scoring-System
An internship-level machine-learning project that trains three classification models, assigns explainable attrition-risk scores, and presents the results in Streamlit.

#The project studies historical employee information and estimates the probability that an
employee may leave the organization. It places each employee into one of three categories:

- **Low risk:** probability below 30%.
- **Medium risk:** probability from 30% to 60%.
- **High risk:** probability above 60%.

The result is a decision-support tool. A prediction is not a certainty and should never be
used alone to make an employment decision.
